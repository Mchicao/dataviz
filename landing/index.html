A serious stack for serious data. Your data stays safe.

DataVIZ is built end-to-end in TypeScript on Effect, a runtime where failures are typed, handled, and tested, never silent.

TypeScript 7

Strict types across the whole product. Models, queries, and UI share one source of truth.

Effect

Typed errors, retries, and timeouts by construction. Nothing fails silently.

Row-level security

Permissions enforced at the data layer, every query respects who is asking.

Encryption & audit

TLS in transit, encrypted at rest, and a traceable lineage for every answer.

GDP-TS

Authorization enforced as compile-time proofs: sensitive operations refuse to run without a verified permission check.

Ultracite

Strict linting tuned against AI slop, the codebase stays clean while agents write code.
